# TEA PARTY

**TEA PARTY**는 PC에 저장된 이미지를 모으고, 자동 태그 분석과 태그·색상 검색으로 다시 찾을 수 있게 하는 **로컬 이미지 라이브러리**입니다.

그림이나 사진이 들어 있는 폴더를 가져오거나 이미지 한 장을 추가하면, TEA PARTY가 **프로그램 내부 저장소에 복사**해 관리합니다. 가져오기 전에 정확히 같은 파일의 SHA-256 해시를 확인해 중복 등록을 피합니다. 이미지 상세 화면에서는 태그를 편집하거나 관련 이미지를 둘러볼 수 있습니다.

앱은 PC의 로컬 웹 서버와 웹 브라우저를 사용합니다. 일반적인 이미지 분석·검색은 PC에서 실행됩니다. **자연어 검색**을 별도로 설정한 경우에만 지정한 외부 API를 이용합니다.

> **가장 짧은 시작 방법:** Windows에 64비트 Python 3.12를 설치하고, 이미지 분석용 `.ckpt` 체크포인트를 준비한 다음 **`teaparty.bat`을 더블 클릭**하세요. 가상환경과 필요한 패키지는 자동으로 설치됩니다. 체크포인트가 없어도 화면은 열 수 있지만, 새 이미지의 AI 태그 분석은 실행할 수 없습니다.

## 1. 설치 전 준비

| 준비물 | 설명 |
|---|---|
| Windows 10/11 64비트 | 원클릭 BAT 실행을 지원하는 환경입니다. |
| Python 3.11~3.13 **64비트** | **3.12 권장.** [Python 공식 다운로드](https://www.python.org/downloads/windows/)에서 설치하세요. |
| 여유 디스크 공간 | PyTorch/CUDA 다운로드, 이미지 복사본, 썸네일을 위해 **수 GB 이상** 확보하세요. |
| 분석용 `.ckpt` 파일 | CAFormer M36 등 **프로그램에 포함된 구조와 호환되는 체크포인트**가 필요합니다. 패키지에는 모델 가중치가 포함되지 않습니다. |

NVIDIA GPU가 있으면 호환되는 CUDA용 PyTorch를 우선 설치하고, CUDA를 사용할 수 없는 경우 CPU용 PyTorch로 전환합니다. CPU 분석도 가능하지만 GPU보다 느릴 수 있습니다. 

### Python 처음 설치하기

1. Python 설치 프로그램에서 **Add Python to PATH** 옵션을 사용할 수 있으면 켜세요. (Windows의 `py` 실행 프로그램을 사용해도 됩니다.)
2. 설치 후 명령 프롬프트에서 `py -3.12 --version` 또는 `python --version`을 실행해 확인할 수 있습니다. 파이썬 버전을 확인해주세요.

## 2. 첫 실행 — `teaparty.bat`만 더블 클릭

1. 프로젝트 ZIP을 원하는 폴더에 **압축 해제**합니다.
2. 프로젝트 루트에 `main.py`, `requirements.txt`, `setup_teaparty.py`, `teaparty.bat`이 함께 있는지 확인합니다.
3. `teaparty.bat`을 **더블 클릭**합니다.
4. 첫 실행에서 다음 작업이 자동 진행됩니다.
5. 이후에는 같은 BAT를 더블 클릭하면 됩니다. **설치 상태가 정상이고 요구사항이 바뀌지 않았다면 재설치를 생략**합니다.

> **첫 설치는 다운로드 용량이 큽니다.** 설치 중 검은 콘솔 창을 닫지 마세요. 설치 오류가 나면 창의 메시지를 확인하세요.

실행 시 열리는 주소는 `http://127.0.0.1:포트번호/` 형태입니다. 포트번호는 실행할 때 자동 결정됩니다. 

## 3. 모델 체크포인트 넣기

자동 태그 분석에는 `.ckpt` **가중치 파일이 필수**입니다. 프로그램은 CAFormer/TResNet 추론 코드와 태그 사전을 자체적으로 포함하지만, 학습 가중치는 제공하지 않습니다.

**기본 CAFormer M36 모델**을 사용한다면 프로젝트 루트에 다음과 같이 배치합니다.

```text
TEA PARTY/
├─ checkpoints/
   └─ example.ckpt            ← 직접 준비한 체크포인트
```

다른 위치에 체크포인트가 있다면 **좌측 하단의 설정 → 모델 및 검색 설정 → 체크포인트**에서 경로를 입력하세요. 체크포인트에 맞는 모델 구조도 선택해야 합니다. 예를 들어 TResNet D 체크포인트는 모델 구조를 `TResNet D`로 선택합니다.

체크포인트가 맞지 않으면 모델 가중치 로딩 오류가 발생할 수 있습니다. 파일 이름만 바꾼다고 다른 모델의 가중치가 호환되지는 않습니다. 출처가 확실하지 않은 체크포인트는 사용하지 마세요.

## 4. 처음 이미지 등록하기

### 폴더에서 여러 장 가져오기

1. 상단 **폴더 추가**를 클릭합니다.
2. 이미지가 들어 있는 폴더를 선택합니다. 하위 폴더의 이미지도 포함됩니다.
3. **폴더 분석 시작**을 누릅니다. 이미지는 `data/managed_images/`로 복사되어 한 라이브러리에 등록됩니다.
4. 분석 진행률을 확인하고, 끝나면 갤러리에서 이미지를 클릭해 태그를 살펴보세요.

**외부 원본 파일은 삭제하거나 이동하지 않습니다.** 내부에 저장한 복사본을 관리하므로 원본 폴더를 나중에 이동해도 등록된 이미지는 그대로 볼 수 있습니다.

### 이미지 한 장 추가하기

상단 **이미지 추가**를 눌러 파일 한 장을 선택하면 됩니다. 지원 확장자는 JPEG/JPG, PNG, WebP, BMP, GIF, TIFF이며 단일 업로드 최대 크기는 **40MB**입니다.

### 중복은 어떻게 처리되나요?

- **등록 단계:** 파일 바이트의 SHA-256 값이 같으면 중복으로 판단하고 **복사·분석을 건너뜁니다**.
- **이미지 상세의 `해시`:** 기존 분석 해시 및 보조 지각 해시·색상 배치로 **크기가 달라지거나 다시 저장된 유사 이미지 후보**를 찾아줍니다. 후보를 자동 삭제하거나 병합하지는 않습니다.

## 5. 주요 기능

| 기능 | 사용 방법 |
|---|---|
| 갤러리 | 이미지 카드를 클릭하면 같은 화면에서 크게 봅니다. 스크롤하면 관련 이미지를 탐색할 수 있습니다. |
| 태그 검색 | 상단 검색창에 `sky, blue eyes`처럼 쉼표로 구분한 태그를 입력합니다. |
| 태그 편집 | 상세 화면에서 태그를 추가·삭제합니다. 태그 이름을 누르면 해당 태그로 검색합니다. |
| 색상 검색 | 왼쪽 **색상 검색**에서 색을 골라 8×8 격자에 칠한 뒤 검색합니다. |
| 같은 해시 | 상세 화면의 **같은 해시** 버튼으로 중복·유사 이미지 후보를 확인합니다. |
| HISTORY | 최근 열어본 이미지가 왼쪽에 표시됩니다. 같은 브라우저의 저장소에 방문 이력이 남습니다. |
| 브라우저 탐색 | 브라우저의 뒤로가기·앞으로가기를 사용할 수 있습니다. |
| 설정 | 왼쪽 하단 설정에서 모델 종류, 체크포인트, CPU/GPU, 확률 기준 등을 조정합니다. |
| 분석 기록 | 왼쪽 **분석 기록**에서 작업 로그와 오류 메시지를 확인합니다. |
| 이미지 삭제 | 상세 화면의 **이미지 삭제**는 관리 복사본, DB·태그·해시 기록, 썸네일을 함께 정리합니다. |

화면은 데스크톱·태블릿·모바일 크기에 맞춰 배치가 달라집니다. 다만 **기본 서버는 PC 자신의 `127.0.0.1`에만 바인딩**되므로, 다른 스마트폰에서 바로 접속되지는 않습니다.

## 6. 파일은 어디에 저장되나요?

```text
data/
├─ library.sqlite3                  이미지 메타데이터·태그·분석 정보
├─ managed_images/                 내부 이미지 복사본 (한 폴더)
│  ├─ example.png
│  ├─ imports.json                  원본 경로 매핑
│  ├─ imports.journal               중간 기록
│  ├─ content_hashes.json           파일 SHA-256 인덱스
│  └─ image_captions.json           가져온 기존 태그 기록
├─ thumbnails/                    갤러리 미리보기
└─ settings.json                  로컬 분석·검색 설정
```

파일 일부는 실제 등록 상태에 따라 아직 생성되지 않을 수 있습니다. 데이터 보관이 중요하다면 **프로그램을 종료한 상태에서 `data/` 폴더 전체**를 백업하세요. SQLite 파일만 백업하거나 `managed_images/`만 복사하면 복구 시 데이터가 어긋날 수 있습니다.

원본 폴더를 다시 추가해도 현재 데이터와 동일한 파일은 해시 확인 후 건너뛰므로 대량 이미지 재등록을 줄일 수 있습니다.

## 7. 문제 해결

### BAT를 눌렀는데 Python을 찾을 수 없다고 나와요

올바른 버전의 Python이 설치되어 있는지 확인하세요. Python 3.12 설치를 권장합니다.

### 첫 실행에서 패키지 설치가 실패해요

인터넷 연결과 디스크 공간을 확인하세요. 일시적인 네트워크 오류라면 BAT를 다시 실행할 수 있습니다. 실패한 설치는 성공 상태로 기록하지 않습니다. 계속 실패하면 `.venv/`만 삭제한 뒤 다시 실행하세요. **`data/` 폴더는 지우지 마세요.**

### NVIDIA GPU가 있는데 CPU로 실행돼요

먼저 명령 프롬프트에서 `nvidia-smi`가 동작하는지 확인하세요. CUDA 버전·드라이버가 설치한 PyTorch와 호환되지 않으면 설치 과정에서 CPU 버전으로 전환할 수 있습니다. GPU 환경을 재시도하려면 그래픽 드라이버를 점검한 뒤 `.venv/`를 삭제하고 BAT를 다시 실행하세요.

### 창은 열리지만 이미지 분석이 안 돼요

`checkpoints/`에 **호환되는 `.ckpt` 체크포인트가 존재**하는지 확인하세요. 분석 기록에 파일 경로, 모델 구조 불일치, 메모리 부족 등의 구체적인 오류가 표시됩니다. GPU 메모리가 부족하면 설정에서 `CPU`를 선택하거나 동시 분석 수를 줄여 보세요.

### 브라우저가 자동으로 열리지 않아요

BAT 창에서 `http://127.0.0.1:.../` 주소를 찾아 직접 브라우저에 입력하세요. 서버 종료 후 이전 주소를 다시 사용하면 접속되지 않을 수 있습니다.

## 8. 고급 실행 (선택)

프로젝트 폴더에서 명령 프롬프트를 열고 실행합니다.

```bat
.venv\Scripts\python.exe main.py
.venv\Scripts\python.exe main.py --browser
.venv\Scripts\python.exe main.py --no-browser
.venv\Scripts\python.exe main.py --port 8000
```

- 기본 실행은 **로컬 서버를 켜고 기본 웹 브라우저를 엽니다**.
- `--browser`: 기본 브라우저 실행을 명시합니다. (기본 동작과 같습니다.)
- `--no-browser`: 브라우저를 자동으로 열지 않고 서버만 시작합니다.
- `--port`: 로컬 서버가 사용할 포트를 지정합니다(기본값 `0`은 빈 포트 자동 선택).
- 이전의 별도 데스크톱 창과 레거시 GUI는 제공하지 않습니다. 폴더 추가에 사용하는 운영체제의 폴더 선택창은 계속 사용할 수 있습니다.

개발자용 설치 점검: `".venv\Scripts\\python.exe" setup_teaparty.py --dry-run`

## 9. 개인 정보·사용 라이브러리

TEA PARTY는 이미지 파일과 검색 인덱스를 **사용자 PC에 보관**합니다. 기본 이미지 분석·태그·색상 검색은 외부로 이미지를 전송하지 않습니다. 선택 기능인 자연어 검색을 직접 설정한 경우, 입력 문장과 등록된 태그 목록이 설정된 API로 전송될 수 있고 별도 요금이 발생할 수 있습니다.

프로젝트에 포함된 추론 코드·태그 사전의 제3자 라이선스는 `image_library/inference/THIRD_PARTY_LICENSES.txt`를 참고하세요. **모델 체크포인트의 이용 조건은 해당 파일을 배포한 제공자에게 확인**해야 합니다.
